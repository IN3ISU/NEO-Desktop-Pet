# 🎭 NEO Anonymous

![NEO Anonymous](neo-banner.png)

### Your Cyber Desktop Companion for macOS

NEO Anonymous is your interactive AI desktop companion for macOS.

A small hacker-inspired character that lives on your desktop, interacts with you and helps you manage your Mac.

## ✨ Features

- 💬 Chat with NEO
- 🖥️ macOS system commands
- 📊 CPU, RAM and disk monitoring
- 🔋 Battery monitoring
- 🌐 Network information
- 🎭 Interactive Anonymous character
- ⚙️ Customizable settings
